# Projects using apb

The projects that run on apb, and whether each is in use. The playbook's rule "An apb change reaches the projects already using apb in the same round" reads this list: a change to how projects run goes to every project marked "yes" under In use, and to no other. Projects are found here, never by searching the computer's folders for an apb-style `CLAUDE.md`, which also finds projects no longer in use.

- To add a project, add a row with its repo and "yes".
- When a project stops being used, change its In use to "no" and keep the row: it records that the project is no longer in use.
